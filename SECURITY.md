# Security Policy

## Supported versions

Only the latest release is supported with security updates.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report privately through
[GitHub Security Advisories](https://github.com/fabiocicerchia/k8s-rightsizer-report/security/advisories/new)
(preferred), or email **<info@fabiocicerchia.it>**.

Please include a description, reproduction steps, and impact. You will get an
acknowledgement within a few days, and a fix or a mitigation plan as soon as
possible after triage.
